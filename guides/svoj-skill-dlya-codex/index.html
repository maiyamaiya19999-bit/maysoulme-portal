Как создать свой первый скилл для Codex

Превращаем повторяющуюся задачу в понятную инструкцию, которую Codex сможет применять снова и снова.

ИИ · Скиллы · 15 минут

Скилл — это твой рабочий процесс, записанный так, чтобы Codex мог точно его повторить.

Тебе не придётся каждый раз заново объяснять правила, стиль и последовательность действий. Один раз собираешь основу, тестируешь её на реальной задаче — и получаешь готовый инструмент для работы.

01. Сначала пойми суть

Скилл нужен не для одной случайной просьбы, а для сценария, который повторяется. Например: оформить заметки как гайд, разобрать сценарий Reels или подготовить структуру контент-плана.

Простая формула: когда использовать → что делать по шагам → каким должен быть готовый результат.

Когда скилл действительно полезен

  • Задача повторяется. Ты уже объясняла её больше одного раза.
  • У тебя есть свой подход. Важны конкретные правила, тон или порядок работы.
  • Результат можно проверить. Понятно, что должно получиться в финале.

02. Собери основу по шагам

ШАГ 01
Выбери один конкретный сценарий
Плохо. «Помогай мне с контентом» — слишком широко.
Хорошо. «Превращай мой черновик в структурированный гайд» — результат понятен.
Совет: если в описании много союзов «и», вероятно, один скилл пытается решать слишком много задач.
Чем уже первый сценарий, тем стабильнее результат.
ШАГ 02
Объясни, когда включать скилл
Назови запросы. Укажи слова и типы задач, при которых нужна эта инструкция.
Добавь границы. Опиши, для каких задач скилл использовать не нужно.
Хорошее описание помогает Codex выбрать правильный инструмент.
ШАГ 03
Запиши процесс так, как делаешь сама
Сначала. Что нужно понять или проверить до начала работы?
Потом. Какие действия идут друг за другом?
В финале. По каким признакам видно, что всё готово?
Совет: замени «сделай красиво» на наблюдаемые критерии: длину, структуру, тон, обязательные блоки.

03. Напиши первый SKILL.md

Для теста достаточно короткого файла: название, описание момента запуска, процесс и требования к результату.

Основа SKILL.md
Копируй → Адаптируй → Тестируй

---
name: guide-maker
description: Оформляет черновик пользователя как понятный пошаговый гайд
---

# Задача
Преврати исходный текст в структурированный гайд.

# Процесс
1. Выдели главный результат для читателя.
2. Собери логичную последовательность шагов.
3. Добавь примеры и финальный чек-лист.
4. Проверь ясность заголовков и формулировок.

# Результат
Готовый материал легко просмотреть и применить.

Важно: первый файл не обязан охватывать все случаи. Он должен хорошо справиться с одним реальным примером.

04. Проверь перед запуском

  1. 01.Название короткое и отражает задачу.
  2. 02.Описание объясняет, когда использовать скилл.
  3. 03.Шаги можно выполнить по порядку без догадок.
  4. 04.Есть понятные критерии готового результата.
  5. 05.Инструкция проверена на одной настоящей задаче.

Три частые ошибки

  • Слишком широко. Один скилл пытается писать, анализировать и оформлять всё сразу.
  • Слишком абстрактно. Есть слова «качественно» и «красиво», но нет критериев.
  • Нет финальной проверки. Результат не сравнивается с требованиями перед ответом.

Начни с простого. Улучшай после реального запуска.
