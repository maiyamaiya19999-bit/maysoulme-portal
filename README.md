# maysoulme — портал

Бесплатная библиотека гайдов + витрина интенсива. Публикуется на GitHub Pages.

## Структура

```
index.html            главная (генерируется build.py — руками не править)
guides.json           реестр гайдов: категории, названия, описания, источники
build.py              сборка: копирует гайды, чинит пути, генерирует главную
guides/<slug>/        собранные гайды
logo-ms.png           логотип
CNAME                 домен (появится после покупки maysoulme.ru)
```

## Как добавить новый гайд

1. Сделать HTML-гайд (скилл `guide`).
2. Прописать блок в `guides.json` — в нужную категорию:

```json
{"slug": "kak-nazvat-v-adrese", "title": "Название", "desc": "Описание для карточки", "tag": "Гайд", "src": "assets/файл.html"}
```

`src` — путь от одного из корней: `assets/` = `~/Desktop/клод/maysoulme-assets`, `repos/` = `~/Desktop/клод/архив/portal-sources`. В `title` можно ставить `<i>` и `<b>` — курсив и жир в заголовке карточки. `bridge` — личный мостик к интенсиву в конце гайда.

3. `python3 build.py`
4. `git add -A && git commit -m "Новый гайд: ..." && git push`

Через минуту гайд живёт по адресу `/guides/<slug>/`.
