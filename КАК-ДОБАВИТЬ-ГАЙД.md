# Как добавить новый гайд на maysoulme.ru

Портал собирается сам. Чтобы новый гайд появился и на своём адресе, и в сборнике на главной,
нужно три вещи.

## 1. Сделать гайд как обычно

Скиллом `guide` — фирменный стиль, белый фон, Libre Baskerville + Inter. Получается один файл `index.html`.

## 2. Добавить в `<head>` четыре строки

```html
<meta name="ms-section" content="content">
<meta name="ms-tag" content="Гайд">
<meta name="ms-title" content="Название для карточки — можно с <i>курсивом</i>">
<meta name="ms-desc" content="Одно предложение: что человек получит. В стиле Майи, на «вы».">
```

`ms-section` — в какой раздел попадёт карточка:

| id | Раздел |
|---|---|
| `reels` | Reels и разговорные ролики |
| `content` | Контент, тексты и смыслы |
| `start` | ИИ с «0» |
| `claude` | Claude и свои ассистенты |
| `life` | ИИ для жизни |

`ms-tag` — что написано над названием: `Гайд`, `Промпт`, `Подборка`, `Скилл`, `Курс`.

Необязательно: `ms-bridge` — личный мостик к интенсиву в конце гайда (одно-два предложения).
Без него подставится общий.

## 3. Положить файл в репозиторий и запушить

Репозиторий: `github.com/maiyamaiya19999-bit/maysoulme-portal`.
Файл кладётся по пути `guides/<адрес-латиницей>/index.html`, например `guides/kak-pisat-huki/index.html`.
Картинки — в ту же папку, ссылки на них относительные.

Проще всего сказать Claude Code: «добавь этот гайд на портал maysoulme в раздел content по адресу kak-pisat-huki».
Он положит файл, проверит meta-теги и запушит.

Через минуту после пуша GitHub сам пересоберёт портал:
- гайд откроется по адресу `maysoulme.ru/guides/kak-pisat-huki/`
- карточка появится на главной в нужном разделе
- внутри гайда будут шапка «← Все гайды», время чтения, оглавление, тёмная тема и блок про интенсив

## Проверить локально (необязательно)

```bash
python3 build.py
```

## Чего не делать

- Не править `index.html` в корне — он генерируется, правки затрутся.
- Не менять `logo-ms.png`, `denistina.ttf`, `politika.html` без Майи.
- Адрес гайда (имя папки) после публикации не переименовывать — сломаются ссылки в постах.
