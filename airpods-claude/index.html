AirPods — голосовой пульт от Claude Code

Настраиваем связку один раз — и задачи Claude можно ставить голосом откуда угодно: Siri, приватный GitHub и облако. Mac при этом может быть выключен.

УСТАНОВКА ~15 МИНУТ · IPHONE + AIRPODS · РАБОТАЕТ В ОБЛАКЕ

Идёте по улице, наговариваете задачу в наушники — и пока доходите до кофейни, Claude в облаке уже всё сделал и прислал уведомление на iPhone.

Моя любимая сцена: гуляю, в голове собирается идея для reels. Раньше она умерла бы в заметках. Теперь я вызываю Siri, говорю «Задача для Claude» и проговариваю поток мыслей — а Claude по скиллу сценариев собирает из него сценарий с хуком, вовлечением и призывом. Остаётся только записать. На этой странице — как поставить себе такую же связку с помощью готового скилла.

01.Как работает связка

AirPods→Siri→команда iPhone→приватная задача в GitHub→Claude Code в облаке→ответ на iPhone

Вы диктуете задачу — команда на iPhone превращает её в задачу (issue) в вашем приватном репозитории на GitHub. Там её подхватывает официальный Claude Code Action и выполняет на сервере GitHub: работает с файлами проекта, пишет тексты, правит страницы, отвечает в ту же задачу. GitHub присылает уведомление, и Siri может прочитать его прямо в AirPods.

Главное: после настройки Mac можно выключить. Claude работает в облаке с файлами, которые лежат в репозитории на GitHub. Файлы, которые есть только на Mac и не загружены в репозиторий, из облака не видны.

02.Что понадобится

  • iPhone + AirPods — с включённой Siri и приложением «Команды» (стоит по умолчанию)
  • Аккаунт GitHub и отдельный приватный репозиторий под задачи — скилл поможет выбрать или создать
  • Подписка Claude Pro или Max (или API-ключ Anthropic) — на ней Claude работает в облаке
  • Claude Code на компьютере — один раз, только для установки
  • Приложение GitHub на iPhone — чтобы приходили уведомления с результатом

03.Установка скилла

Всю настройку делает готовый скилл — он сам скопирует рабочий процесс в ваш репозиторий, подскажет, где взять токены, и проведёт по шагам на iPhone. Вам нужно запустить его одним из двух способов.

Способ 1 — команда в терминале
скопируйте и вставьте в терминал
npx skills add maiyamaiya19999-bit/airpods-claude-cloud
Способ 2 — просто попросить Claude
отправьте в Claude Code это сообщение
Установи скилл https://github.com/maiyamaiya19999-bit/airpods-claude-cloud и помоги настроить связку AirPods → Claude в облаке

Дальше Claude всё сделает сам и по ходу попросит у вас три вещи: выбрать репозиторий, установить приложение Claude для GitHub (только на этот репозиторий) и добавить секрет с токеном Claude. Токены нигде не показываются и не публикуются — скилл специально построен так, чтобы они не попали ни в чат, ни в файлы.

Открыть скилл на GitHub

04.Команда на iPhone

Последний кусочек — голосовая команда. Скилл даст точную пошаговую инструкцию, здесь — общая картина, чтобы вы понимали, что собираете.

  1. 1.Создайте в «Командах» команду «Задача для Claude»Название и есть фраза для Siri — произносите его, и запускается диктовка.
  2. 2.Действие «Диктовка текста»Останавливается после паузы — наговорили задачу и замолчали.
  3. 3.Текст задачи с обращением @claudeШаблон уже включает правило: ничего не публиковать и не удалять без отдельного подтверждения.
  4. 4.Отправка в GitHubДействие «Получить содержимое URL» создаёт задачу в вашем репозитории по токену, который работает только с ним.
  5. 5.Siri подтверждает голосом: «Задачу отправила»Результат придёт уведомлением GitHub — Siri может прочитать его в AirPods.
Важно: внутри настроенной команды хранится ваш GitHub-токен. Никогда не делитесь готовой командой и не выкладывайте её скриншоты с открытыми полями — токен как пароль.

05.Первый запуск

Начните с безобидной проверки — вызовите Siri, скажите «Задача для Claude» и продиктуйте:

Тестовая задача
ничего не меняет — только читает
Прочитай README этого репозитория и ответь в задаче четырьмя пунктами, файлы не меняй
  • Siri подтвердила отправку — команда сработала
  • В репозитории появилась задача, и в ней Claude оставил комментарий с результатом
  • На iPhone пришло уведомление GitHub

Если все три пункта сошлись — связка живая, можно давать настоящие задачи: собрать пост, поправить страницу, проверить ссылки, написать сценарий.

06.Правила безопасности

  • Один репозиторий. Токен команды и приложение Claude имеют доступ только к выбранному репозиторию — не расширяйте его
  • Опасное — руками. Публикации, оплаты, удаление данных и доступ к секретам остаются за ручным подтверждением, голосом такое не делается
  • Токены — никому. Не вставляйте их в чат, файлы, задачи или скриншоты; если телефон побывал в чужих руках — перевыпустите токен
  • Облако видит только GitHub. Всё, с чем Claude должен работать, должно быть загружено в репозиторий

AirPods становятся голосовым пультом от вашего облачного сотрудника.
