# Как прикрутить домен maysoulme.ru

Сейчас портал живёт по временному адресу:
https://maiyamaiya19999-bit.github.io/maysoulme-portal/

## 1. Купить домен

Любой регистратор: reg.ru, timeweb, beget. Домен `maysoulme.ru` — примерно 200–900 ₽ за первый год.
Если .ru занят — вторые кандидаты: `maysoulme.com`, `maysoulme.me`.

## 2. Прописать DNS у регистратора

В разделе «DNS-записи» домена добавить **четыре A-записи** для корня (`@`):

```
@   A   185.199.108.153
@   A   185.199.109.153
@   A   185.199.110.153
@   A   185.199.111.153
```

И одну CNAME для www:

```
www  CNAME  maiyamaiya19999-bit.github.io.
```

(это официальные адреса GitHub Pages, они одинаковые у всех)

## 3. Сказать это Claude — дальше всё сделаю я

Дальше нужно: положить файл CNAME в репозиторий, включить домен в настройках Pages,
дождаться сертификата, включить Enforce HTTPS и проставить редиректы со старых адресов
(`python3 make-redirects.py`). Просто напиши «домен куплен, DNS прописала».

Обычно DNS расходится за 15–60 минут, сертификат выпускается ещё минут за 15.
