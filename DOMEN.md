# Домен maysoulme.ru

Домен куплен на reg.ru 06.09.2026. Портал пока живёт по временному адресу
https://maiyamaiya19999-bit.github.io/maysoulme-portal/

## Что нужно сделать в панели reg.ru (5 минут)

Домены → **maysoulme.ru** → «DNS-серверы и управление зоной» → «Управление зоной».

Удалить записи типа A, которые reg.ru поставил на свой хостинг (парковку), и добавить
**четыре A-записи** для корня — в поле «Субдомен» оставить пустым или поставить `@`:

```
@   A   185.199.108.153
@   A   185.199.109.153
@   A   185.199.110.153
@   A   185.199.111.153
```

И одну CNAME для www:

```
www   CNAME   maiyamaiya19999-bit.github.io.
```

(точка в конце обязательна)

Это официальные адреса GitHub Pages — одинаковые для всех сайтов.

**Reg.Host не нужен** — сайт хостится на GitHub бесплатно. Хостинг можно не настраивать.

## Дальше делает Claude

Как только записи разойдутся: положить CNAME в репозиторий, включить домен в настройках
Pages, дождаться сертификата, включить HTTPS и запустить `python3 make-redirects.py --apply`,
чтобы старые ссылки вели на новые адреса.

## Готово — 07.09.2026

Домен работает: **https://maysoulme.ru** (www и http перекидывают на него), сертификат GitHub выпущен,
HTTPS принудительный. Старые адреса гайдов (anketa.mayasoul.ru/…, github.io/…) редиректят на новые.

Что было по пути: после смены DNS-серверов в кабинете Рег.ру реестр .ru публиковал новое делегирование
около 6 часов; старые серверы хостинга (ns*.hosting.reg.ru) продолжали отвечать за зону, из-за чего
GitHub ещё час не выпускал сертификат — помогло снять и заново привязать домен в настройках Pages.
Reg.Host не нужен, можно не продлевать.
